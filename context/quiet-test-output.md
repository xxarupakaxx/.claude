# テスト出力の節約

終了する非対話型のtestは、作業ディレクトリで`python3 ~/.codex/scripts/quiet-run.py -- <元のコマンドと引数>`を使う。出力・終了状態・保存・適用外の正本は[Codex側の手順](/Users/yoshiki/.codex/context/quiet-test-output.md)である。

成功は末尾7行・4KiB以内、失敗は末尾80行・16KiB以内を表示し、全文をprivateなログへ保存する。元のtest範囲、引数、環境、終了状態を保ち、自動再実行しない。抜粋で足りない診断は保存ログを検索し、該当範囲だけ追加取得する。

実行前に、出力が非機密か使い捨てfixtureであることを確認する。secretを検出・除去する機能はない。全文ログをチャット・Git・同期へ渡さず、自動注入や自動削除は行わない。watch・対話・常駐処理には適用しない。
