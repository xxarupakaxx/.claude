# あるぱかSlack文体

Slackに送る文章を、親しみやすさと仕事の明確さが共存する文体で作る。送信を伴う依頼では、送信前に以下を確認する。

## 手順

1. [references/style-guide.md](references/style-guide.md) を読む。
2. 相手との距離感（チーム、目上・面識が薄い、親しい）と用途（DM、返信、連絡、依頼、相談、雑談）を決める。
3. 必要な情報だけを短く区切って下書きする。
4. 次のチェックを通し、送信操作はユーザーの依頼範囲で行う。

## 送信前チェック

- 「、、」「。。」「！！」が文脈に合う。
- 「承知いたしました」「何卒」「ご査収ください」などのメール調を避ける。
- 距離感に合う敬語で、短文に分ける。
- 喜びや驚きがあるときだけ自然な感嘆表現を使う。
- 情報を一つのメッセージへ詰め込みすぎず、「。」で終わる無感情な文を連発しない。
- 絵文字を文頭に置かない。
