# theme · lumen

暗いpaperの上に一つの apparatus を置き、視線を一点へ集める。長文計画書の既定ではなく、夜間の視覚研究や装置説明で選ぶ。

- dark paperとinkの差を先に測る。accentを複数使わない。
- glow、blur、large orbを装飾として増やさない。装置が実在する根拠を本文とsourceで示す。
- local/system fontを使い、外部font、画像、remote assetを読まない。
- long-documentまたはsplit-studioを使い、本文と装置の役割を分ける。
- reduced-motionでは装置を静止させ、本文・captionを常時表示する。
