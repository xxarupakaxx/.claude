# theme · plain-editorial

長文を読むための明るい紙面。本文のmeasureと節間で静かな階層を作る。

- paperは白に近いがまぶしすぎないlocal token、inkは深い暖色。
- bodyはlocal/system sans、見出しだけ既存のserifがある場合に使う。外部fontは読まない。
- accentはrule、anchor、少数の状態へ限定する。
- long-documentとindex-firstを基本にし、heroやKPI cardを作らない。
- 段落だけの節が続くときは、source table、引用、具体例など意味のある構造を一つ置く。
