# UI Visual Design Defaults

新規UI作成時、または既存のデザインシステムが無い場合の既定値。

## 既定値

1. 色はRadix UI Colorsを使い、その用途ガイド（スケールの段階ごとに背景・境界線・テキスト等）に従う。
2. 配置は光学的な揃え（optical alignment）を優先する。入れ子の角丸は同心円にする（外側の半径 = 内側の半径 + padding）。
3. 線・境界線が必要なら0.5pxにする。
4. アニメーション・トランジションは最小限にする。必要な場合の既定はease-out・250ms。
5. 1画面のフォントサイズは最大4種類、理想は3種類にする。最小12px。階層はサイズではなくウェイト・色・余白で表す。
6. ユーザーに判断を求める操作を最小限にする。避けられない場合は、ユーザーがもともと選ぶつもりの場所に置く。どの機能・要素が本当に必要か見直し、情報に優先順位を付けて整然と並べる。
7. 角丸と影を安易に使わない。特にカード左端の色付きストライプは避ける。使う場合は機能に見合った値を選ぶ。

## 境界

- これらは新規UI、またはプロジェクトにデザインシステムが無い場合の既定値。プロジェクトに独自のデザインシステム・デザイントークン・ブランドカラー・コンポーネントライブラリ（theme、Tailwind設定、design tokens等）がある場合はそちらを優先する。依頼なくパレットをRadix Colorsへ置き換えたり、境界線の太さをプロジェクト全体で変えたりしない。
- アクセシビリティを保つ。0.5pxの境界線や色でも必要なコントラストを満たす。`prefers-reduced-motion` を尊重する。
